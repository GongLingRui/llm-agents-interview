# Engineering Experience

> 工程经验：可复现的坑、门禁数字、落地 playbook、团队政策与真实约束下的取舍。

## 职责

- 记录 **落地经验**（怎么配门禁、踩过什么坑、如何在成本/延迟/安全约束下做决策）
- 回链对应的概念 Canonical（机制正文只在 `concepts/`）

## 非目标

- 不复制 / 改写 `concepts/` 里的机制正文
- 不把课程笔记写在这里（课程目录独立于本双支柱）
- 不为「显得完整」堆空话；占位目录仅表示可补充落点

## 与 concepts 的关系

| | concepts/ | engineering-experience/ |
|--|-----------|-------------------------|
| 写什么 | 定义、机制、边界、评测框架 | 实战心得、数字、playbook |
| 混写 | 禁止 | 禁止 |
