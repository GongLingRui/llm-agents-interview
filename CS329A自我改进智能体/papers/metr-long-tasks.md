# Measuring AI Ability to Complete Long Tasks（METR）

- **链接**：https://arxiv.org/abs/2503.14499  
- **关联讲次**：L17（主课详尽口播）

## 问题

如何用与人类专业人士校准的**时间地平线**度量 AI 能力进步，而非易饱和的短题准确率？

## 机制

- 任务套件：SWAA（秒级）+ HCAST（分–时）+ RE-Bench（研究工程，可达 ~8h）；约 170 题  
- 人类基线：~5 年经验专业人士成功完成时间（几何平均难度）  
- Agent 多 attempt → 成功率曲线 → 50% / 80% 等 **time horizon**  
- 对照模型发布日期看趋势

## 课堂强调数字

| 点 | 值 |
|----|-----|
| 50% horizon 趋势 | ~**每 7 个月翻倍** |
| GPT-2 → Claude 3.7 | ~2 秒 → ~**59 分钟**（50%） |
| 同模型 80% | ~**15 分钟**量级（课上） |
| HCAST / SWAA / RE-Bench | ~97 / 66 / 7 |
| Contractor vs maintainer | **5–18×** 更慢；模型≈低上下文 contractor |

## 失败模式（课上）

规划差、工具错、推理错、过早放弃、重复循环。

## 工程 Takeaway

- 同时报 50% 与高可靠地平线。  
- SWE-bench 可能偏乐观（污染 + 低估人类时间）。  
- 自动打分、单 agent、少惩罚 ≠ 真实部署。

## 一句话

用「人类要多久」标定 AI 能可靠完成多长的任务；能力指数涨，可靠性仍落后。
